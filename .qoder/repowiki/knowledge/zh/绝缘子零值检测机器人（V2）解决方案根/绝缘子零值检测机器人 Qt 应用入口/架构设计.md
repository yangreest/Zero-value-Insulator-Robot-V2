本模块为整个应用的单一可执行入口，仅包含三个文件：main.cpp 作为 Qt 应用程序的启动点，负责在 _DEBUG 构建下通过 AllocConsole 与 freopen 重定向 stdout 到控制台，随后创建 QApplication 实例并显示 UI/Insulator_Zero_Value_Detection_Robot.h 中定义的主窗口；resource.h 由 Visual C++ 资源编译器生成，用于 Insulator_Zero_Value_Detection_Robot.rc 资源脚本中的 ID 占位符；单点定标协议与流程_V1.0.html 为与该入口同级的文档说明文件，不参与编译。依赖方向单向向外：入口 → Qt 框架 + UI 层，不反向依赖业务逻辑。

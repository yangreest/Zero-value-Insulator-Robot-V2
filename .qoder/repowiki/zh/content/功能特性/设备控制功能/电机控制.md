## 简介
本文件面向绝缘子检测机器人的电机控制系统，聚焦以下目标：
- 说明行走电机、卷扬电机、安全轮电机和成像板电机的控制逻辑。
- 解释 DeviceRun、DeviceStop、DeviceBreak 等核心控制命令的实现机制。
- 描述速度模式与角度模式的配置和使用方法。
- 说明电机状态监控与故障检测机制（含电压异常阈值与运行超时保护）。
- 提供电机控制的 API 接口说明与实际使用示例。
- 给出电机参数配置与安全阈值设置指南。
- **新增**：详细说明舵机到位反馈处理系统，包括CServoArrivalFeedback数据结构解析、回调注册机制和±20步阈值判断。

## 架构总览
电机控制采用"上层业务 -> 协议封装 -> 下位机执行 -> 心跳反馈"的闭环架构：
- 上层通过协议类的静态方法构造控制帧。
- 协议层通过回调将帧发送至 TCP 客户端。
- 下位机执行后，周期性上报心跳，包含四类电机状态。
- 上层订阅心跳回调，更新 UI 并驱动后续流程。
- **新增**：舵机到位反馈通过独立回调机制处理，支持±20步精度判断。

### 电机控制命令实现机制
- DeviceRun：支持两种重载
  - 速度模式：target、enable、runMode、speed（单字节速度）
  - 角度模式：target、enable、runMode、runAngel、speed（角度+双字节速度大端）
- DeviceStop：对指定 target 执行停止。
- DeviceBreak：全局急停（对所有电机生效）。
- DeviceStopAll：停止全部电机。
- TurnOnAll/TurnOffAll：总电源开关。

上述方法均通过统一的 GetCmdData 封装协议帧，包含包头、长度、序号、命令字、数据域、校验和、包尾。

### 舵机到位反馈处理系统
**新增**：完整的舵机到位反馈处理系统，包括以下关键组件：

#### CServoArrivalFeedback数据结构
- 结果字段：0x01表示正常到位，0x00表示超时未到位
- 目标位置：0-4095步范围的大端无符号16位整数
- 实际位置：0-4095步范围的大端无符号16位整数，表示上报瞬间舵机的真实位置
- 到位判断：|实际位置-目标位置| ≤20步（约±1.8°）

#### 回调注册机制
- RegisterServoArrivalCallBack：注册舵机到位反馈回调函数
- 回调函数签名：std::function<void(const CServoArrivalFeedback&)>
- 回调触发时机：主控板主动上报运动结束或超时后的结果

#### 数据处理流程
- 协议解析：在Parse函数中处理CMD=0x1A的舵机到位反馈帧
- 数据验证：检查载荷长度至少为5字节（结果1B + 目标位置2B + 实际位置2B）
- 回调触发：解析成功后调用注册的回调函数

## 性能与安全特性
- 心跳线程：独立线程周期性发送心跳，避免阻塞主流程。

  - **新增**：舵机到位反馈±20步精度判断，确保定位准确性。
- 错误处理：协议层在解析失败或未知类型时丢弃当前帧，避免污染后续数据。
- **更新**：舵机控制可靠性提升，通过改进的使能验证逻辑和优化的超时计算机制。

## 故障排查指南
- 连接与心跳
  - 检查 UI 的连接状态与心跳计数是否递增。
  - 确认心跳周期配置是否正确。
- 电机无响应
  - 确认总电源已开启（TurnOnAll）。
  - 检查 DeviceRun 的目标电机、使能位、运行模式与速度/角度参数。
  - 查看心跳中的电机状态向量，确认使能与状态位变化。
- 电压异常
  - 核对协议配置中的各电机电压异常阈值是否合理。
  - 若频繁触发异常，检查供电与负载情况。
- 运行超时
  - 调整成像板运行时间阈值，确保任务能在限定时间内完成。
- 舵机到位问题
  - **新增**：检查舵机到位反馈回调是否正常注册和触发。
  - 确认±20步阈值判断是否符合预期。
  - 查看日志中的目标位置与实际位置偏差。
- 日志与回调
  - 注册设备日志回调，观察协议层输出。
  - 检查传感器数据回调与校准回调是否正常触发。
  - **新增**：检查舵机到位反馈回调的注册状态和处理逻辑。

# 报告富文本化改造计划

## 现状摘要
- 左侧导航"检测报告"按钮（`pBreport`）切换到 `stackedWidget_3` 第 2 页报告列表页
- "生成报告"按钮有两处：工单管理页 `pBNewReport`（弹 NewReportDialog）、检测页隐藏面板 `pushButton_30`（写死测试数据的 docx 测试代码）
- 现有 `CWriteReports` 为 docx 模板方案；工单数据含线路/杆塔/串型/片数/回路/电流类型/检测单位/人员/起止时间/备注，测量数据为 JSON `{侧别: {相别: [值...]}}`（双联按 [内,外] 成对）
- Qt 模块已含 core;gui;widgets，导出 PDF 用 QtGui 自带 `QPdfWriter`，无需新增模块

## 实施步骤

### 步骤 1：新建 HTML 富文本报告模板
- 新建 `Insulator_Zero_Value_Detection_Robot/Report/ReportTemplate.html`，占位符用 `${key}`：
  - `${ticketId}`、`${lineName}`、`${poleNumber}`、`${bunchType}`、`${sliceNum}`、`${loopType}`、`${currentType}`、`${detectionUnit}`、`${detectionPerson}`、`${startTime}`、`${endTime}`、`${remark}`、`${mearTable}`、`${conclusion}`
- 结构：标题"绝缘子零值检测报告"、报告编号、基本信息表（工单字段）、测量数据表（`${mearTable}` 占位）、检测依据/结论、备注
- 复制一份到部署目录 `RunDir/ReportTemplate.html`（与 Config.xml 同目录约定，Release 下 `WHSD_Tools::GetAbsolutePath` 解析到 exe 目录）
- **验证**：模板文件存在于源码目录与 RunDir

### 步骤 2：扩展 Report 模块 `WriteReports.h/.cpp`
- 新增 `static QString FillHtmlTemplate(const QString& strTemplate, const QHash<QString, QString>& mapData);`：替换 `${key}`，值做 HTML 转义（`& < >`）
- 新增 `static QString BuildMearTableHtml(const QJsonObject& mapTicketMearData, bool bDouble);`：按 JSON 结构生成测量数据表 HTML（行 = 最大片数，列 = 侧别×相别，双联每相拆内侧/外侧，片号行头，空数据输出占位行）
- 新增 `static bool ExportHtmlToPdf(const QString& strHtml, const QString& strPdfPath);`：`QTextDocument::setHtml` + `QPdfWriter`（A4、合理页边距）写出 PDF，目录不存在自动创建
- **验证**：编译无错误

### 步骤 3：新建预览报告弹窗 `UI/PreviewReportDialog.h/.cpp/.ui`
- QDialog（深色样式与 NewReportDialog 一致），内含 `QTextBrowser`（富文本预览）
- 底部按钮："导出PDF"（`QFileDialog::getSaveFileName`，默认文件名 `<报告编号>.pdf`，调用 `ExportHtmlToPdf`，成功提示）、"关闭"
- 接口：`void SetReportHtml(const QString& strHtml);`
- **验证**：编译无错误

### 步骤 4：修改主窗口 `.ui`（工单管理页按钮）
- 在 `Insulator_Zero_Value_Detection_Robot.ui` 工单管理页 horizontalLayout 中 `pBNewReport` 之后新增 `QPushButton`：name=`pBPreviewReport`，文本"预览报告"，样式复制相邻 `pBNewReport`
- **验证**：uic 编译通过，按钮出现在工单管理页

### 步骤 5：修改主窗口 `Insulator_Zero_Value_Detection_Robot.h/.cpp`
- InitUI 增加 `ui.pBreport->setVisible(false);`（隐藏"检测报告"导航按钮，报告页随之不可达）
- 头文件：新增槽 `void On_PreviewReport_Click();`、辅助 `bool GenerateCurrentTicketReport();`、`QString BuildReportHtml();`、成员 `QString m_strLastReportHtml;`、`PreviewReportDialog* m_pPreviewReportDialog;`
- 重写 `On_NewReport_Click()`（工单管理页"生成报告"）：
  1. 校验当前工单已加载（`m_strTicketId` 非空，否则提示"请先加载工单"）
  2. 收集工单字段（线路/杆塔/串型/片数/回路/电流类型/单位/人员/起止时间/备注）→ `QHash<QString, QString>`
  3. 读取 `ReportTemplate.html`（`WHSD_Tools::GetAbsolutePath`），缺失时用代码内置默认模板兜底
  4. `FillHtmlTemplate` + `BuildMearTableHtml` 生成最终 HTML，存入 `m_strLastReportHtml`
  5. 导出 PDF 到默认目录 `<exe目录>/报告/<线路>_<杆塔>_<报告编号>.pdf`，弹提示显示路径
  6. 更新 `m_bGenerateReport` 标志并写 Config.xml
- `On_WriteReport_Click()`（隐藏面板按钮）改为调用同一 `GenerateCurrentTicketReport()`，删除写死的 docx 测试代码
- 新增 `On_PreviewReport_Click()`：校验工单 → `m_strLastReportHtml` 为空则先生成 → 弹 PreviewReportDialog
- BindAction 增加 `pBPreviewReport` 连接
- **验证**：编译通过；运行时行为见步骤 7

### 步骤 6：注册构建文件 `Insulator_Zero_Value_Detection_Robot.vcxproj`
- 参照 NewReportDialog 的条目格式，加入 PreviewReportDialog.h（ClInclude/QtMoc）、.cpp（ClCompile）、.ui（QtUic）
- **验证**：MSBuild 全量编译通过

### 步骤 7：整体功能验证（人工/程序内验证点）
1. 启动软件：左侧导航无"检测报告"按钮，无法进入报告列表页
2. 未加载工单点"生成报告/预览报告"：提示"请先加载工单"
3. 加载工单 → "生成报告"：默认目录生成 PDF，可用 PDF 阅读器打开且中文正常
4. "预览报告"：弹窗显示富文本（标题/信息表/数据表/结论齐全，与 PDF 一致）
5. 预览弹窗"导出PDF"：选择路径保存成功
6. 特殊字符（`<`、`&` 等线路名）显示正常不破坏排版
7. 无测量数据的工单：报告表格显示空/占位，不崩溃

## 关键假设

- 报告字段仅用工单现有字段，不含电压等级（用户已确认）
- 按钮位置在工单管理页（用户已确认）

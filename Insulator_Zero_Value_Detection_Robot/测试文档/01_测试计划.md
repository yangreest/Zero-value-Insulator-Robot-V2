## 1. 概述

### 1.1 测试目的

对绝缘子零值检测机器人上位机软件进行系统性的功能测试，验证以下目标：

1. 软件各项功能与预期设计一致，满足现场绝缘子零值检测作业需求；
2. 检测数据（表格、曲线、测量截图、报告 CSV）准确、完整、可追溯；
3. 软件与机器人控制板、摄像头、手柄等外设协同工作正常；
4. 异常场景下软件表现稳定，不出现界面卡死、数据丢失等问题；
5. 输出可评估的测试报告（含截图/现场照片证据），作为软件验收与发布的依据。

### 1.2 测试范围

本计划覆盖上位机软件的以下功能模块：

| 模块编号 | 模块名称 | 主要功能点 |
|---|---|---|
| M1 | 启动与初始化 | 程序启动、最大化显示、无边框窗口、配置加载（Config.xml）、设备日志、心跳与状态刷新 |
| M2 | 通信连接 | TCP 连接控制板、连接状态显示、心跳计数、断线表现 |
| M3 | 状态显示 | 行走/安全电机状态、总电源、设备电池、传感器电池、传感器状态、固件版本 |
| M4 | 视频显示 | 左/右摄像头连接与显示、新款 RTSP 相机（主/子码流） |
| M5 | 机器人手动操作 | 总开/总关、前进/后退/停止、探针向内/向外/复位、手动测量 |
| M6 | 键盘控制 | Q/E/R/A/D/S/空格/方向键 快捷键 |
| M7 | 手柄控制 | XInput 手柄方向键与检测按键映射 |
| M8 | 工单管理 | 新建/修改/删除/加载工单、列表查询与重置、单双联与回路数配置 |
| M9 | 测量流程 | 内测→外侧两步自动测量、4s 等待弹窗、结果回显、指示灯、防重复触发 |
| M10 | 表格与曲线 | 动态列（随相别/双联拆分）、行数随片数、实时填值、独立曲线、Splitter 布局 |
| M11 | 重测 | 删除最近一次测量数据并重新测量（表格/曲线/指示灯/截图序号同步回退） |
| M12 | 测量截图 | 测量前自动截图、目录与文件名规范、失败日志 |
| M13 | 报告管理 | 新建报告（继承工单数据）、重复报告确认、列表查询与重置、测量数据 CSV 导出 |
| M14 | 设置页面 | 探针角度、电机速度、机器人 IP、摄像头 IP、OTA、绝缘阈值保存 |
| M15 | 数据持久化 | 工单/报告/配置写入 Config.xml，重启后恢复 |
| M16 | 异常与稳定性 | 未连接设备操作、测量中断开、长时间运行、重复点击 |

## 3. 测试策略

### 3.1 测试类型

| 测试类型 | 说明 |
|---|---|
| 功能测试 | 逐条验证各功能点是否符合预期（主测试类型，按《02_测试用例.md》执行） |
| 接口测试 | 验证软件与控制板（TCP/协议）、相机、手柄的交互 |
| 异常测试 | 未连接设备、连接中断、非法输入、重复触发等场景 |
| 边界测试 | 片数上限（60 片）、数据满后测量限制、IP 非法输入等 |
| 稳定性测试 | 连续测量多相/多杆塔、长时间运行、频繁切换页面 |

### 3.2 优先级定义

| 优先级 | 定义 |
|---|---|
| P0（高） | 核心功能，影响作业流程与数据正确性，必须通过 |
| P1（中） | 重要功能，影响部分使用体验，应通过 |
| P2（低） | 一般功能/界面优化项，尽力通过 |

### 3.3 测试执行方式

1. 按模块顺序执行，优先执行 P0 用例；
2. 每条用例执行后即时记录结果与截图，填写《03_测试报告模板》；
3. 截图/现场照片命名规范：`TC-XXX_步骤N.png`、`TC-XXX_现场.jpg`，与用例编号对应，便于报告索引；
4. 发现缺陷时记录缺陷编号（BUG-XXX）、复现步骤、严重等级，并拍照/截图留证。

### 3.4 通过/失败准则

- **通过**：实际结果与预期结果完全一致；
- **失败**：实际结果与预期结果不一致，或出现崩溃、卡死、数据错误；
- **阻塞**：因环境/前置缺陷无法执行；
- **不适用（N/A）**：当前版本未实现或该环境无法验证的功能（在报告中说明原因）。

### 3.5 测试通过标准（发布准则）

1. P0 用例通过率 100%，无未关闭的致命/严重缺陷；
2. P1 用例通过率 ≥ 95%；
3. 无影响测量数据正确性与安全操作（探针/行走误动作）的缺陷；
4. 所有失败用例均有明确的缺陷记录与整改结论。

## 6. 缺陷管理

### 6.1 缺陷严重等级

| 等级 | 定义 | 示例 |
|---|---|---|
| A-致命 | 系统崩溃、数据丢失、危险动作（电机/探针失控） | 软件闪退；测量数据丢失 |
| B-严重 | 核心功能不可用或数据错误，无规避方法 | 测量值无法回填；截图目录错误 |
| C-一般 | 功能部分失效，有规避方法 | 过滤不生效但可手动查找 |
| D-轻微 | 界面/提示文案等不影响使用 | 文案错别字、图标样式 |

### 6.2 缺陷状态流转

`新建 → 已确认 → 修复中 → 待回归 → 已关闭 / 重新打开`

## 7. 风险与应对

| 风险 | 影响 | 应对措施 |
|---|---|---|
| 现场无真实绝缘子串 | 测量数据类用例无法执行 | 使用试验绝缘子串或控制板模拟测量数据；标记 N/A 并说明 |
| 相机/手柄型号差异 | 视频、手柄用例执行受阻 | 提前确认设备型号与 IP 配置；备用旧款相机 SDK |
| 控制板未就绪 | 通信类用例全部阻塞 | 测试前先完成通信链路检查（Ping + 连接状态显示） |
| 设置页面部分按钮未绑定事件 | 相关用例无法验证 | 执行前以代码绑定情况为基准，未实现项标记 N/A，报告中列为"已知限制" |
